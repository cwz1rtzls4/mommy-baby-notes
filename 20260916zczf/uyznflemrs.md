# 【在线义诊】糖尿病真的可“逆转”，密码在这里！

> 更新时间：2026-09-16 (UTC+8)

目前，中国糖尿病患病人数已居全球首位，预计2030年将增长至1.6亿，如此沉重的数据让我们不得不反复来唠叨“糖尿病”。

很多人认为得了糖尿病也没什么，慢性病嘛，慢慢来。其实，如果不能早期意识到这个病的危害，到后来可能发展成一身病。真正可怕的不是糖尿病，而是糖尿病引起的并发症！

但是，你知道吗？**糖尿病是可以“逆转”的！**医学上也叫“**糖尿病缓解**”。想要逆转糖尿病，关键得掌握好这几个“**密****码**”~~

**尽早识别糖尿病前期**

糖尿病前期，是指血糖已经开始升高，但还没有达到糖尿病的诊断标准，包括空腹血糖受损和糖耐量减低。

和糖尿病一样，糖尿病前期可能出现烦渴多饮、多尿、多食、不明原因体重下降等表现，也可能没有任何症状，需通过体检才能早期发现。

**哪些人群需要定期体检筛查呢？**

✦ 年龄超过40岁；

✦ 超重或肥胖；

✦ 有糖尿病家族史；

✦ 体力活动少；

✦ 有高血压、高血脂等心血管疾病的高危因素；

✦ 多囊卵巢综合征患者；

✦ 长期接受抗精神病药物或抗抑郁药物治疗的患者。

糖尿病前期是身体发出的一种预警，不仅仅预示着发生糖尿病的风险增加，更要命的是，还没等发展成真正的糖尿病，这种高血糖状态就已经在悄悄损害你的健康了，心血管疾病、微血管病变、肿瘤、痴呆、抑郁等疾病都可能与它相关。

抓住这个关键点，进行生活方式的干预治疗，合理膳食、适度运动，可以显著降低糖尿病发病率，实现“逆转”。

**部分早期的2型糖尿病患者**

我国糖尿病患病人群中，2型糖尿病患者数量接近90%。2型糖尿病是由于体内胰岛素抵抗及胰岛β细胞功能缺陷等原因导致的血糖升高，这类患者往往合并肥胖、脂肪肝、高血脂等代谢紊乱，且在发病初期还保存了部分胰岛功能。

这部分患者如果尽早进行生活方式和药物干预，纠正高糖毒性和改善胰岛素抵抗后，可能达到在不使用降糖药物治疗的情况下，血糖仍处于达标或正常状态。

新诊断2型糖尿病伴肥胖患者，如果在1年以内，通过严格饮食营养控制联合运动治疗，部分联合胰高糖素样肽-1受体激动剂等药物，使体重减轻10kg以上（最好15kg以上）或10%以上，达到糖尿病缓解的机会很大。

对于重度肥胖、体质指数≥32.5kg/m2的2型糖尿病患者，经生活方式干预及药物治疗效果不佳，也可以考虑采用代谢手术的方式实现糖尿病缓解。

对于新诊断或病程短的2型糖尿病患者，如果糖化血红蛋白≥10%，空腹血糖≥11.1mmol/L，短期应用早期胰岛素强化治疗，也有助于缓解2型糖尿病。

目前**2型糖尿病缓解的标准**是停用降糖药物至少3个月后，糖化血红蛋白<6.5%，如果存在贫血等因素导致糖化血红蛋白不能反映真实血糖水平时，也可用空腹血糖＜7.0mmol/l作为替代标准。

**吃 动 平 衡**

要想实现逆转，吃动平衡很重要。

**首先要管住嘴**

不是说得了糖尿病就什么都不能吃、不敢吃，最重要的饮食治疗反而讲究的是“平衡”。“平衡”的基本原则是食物多样，保证营养摄入全面、充足，少油少盐限糖限烟酒。

**✦**** 主食要定量：**碳水化合物主要来源以全谷物、豆类、蔬菜等为好，水果要限量；简单估计碳水化合物提供的能量占总能量45%~55%，略低于一般健康人；相当于一天碳水化合物总量为200~300g。其中全谷物、豆类等升糖指数低的食物，应占主食的1/3以上。

**✦**** 餐餐有蔬菜：**每天500g，其中深色蔬菜占一半以上；

**✦**** 保证优质蛋白：**天天有奶类和大豆，常吃鱼、禽，适量蛋和畜肉，这些是蛋白质的良好来源；建议每天一盒牛奶、一个鸡蛋，肉类每天200~300g；

**✦**** 减盐限糖限油：**减少肥肉摄入，少吃烟熏烘烤、腌制等加工肉类制品，控制盐、糖和油的使用量；

**✦**** 学习食物交换份算法：**一个“食物交换份”是指能产生90千卡热量的食物。将食物按照其来源及营养成分的不同，分为几大类，分别是谷薯类、蔬菜类、肉蛋豆类、乳类、油脂类，同类食物的营养成分含量及比例大致相同。根据体重、运动量计算总热卡，计算每天需要吃的份数，根据自己的饮食习惯，选择喜欢的食物种类，将其按照比例均分到早中晚三餐中即可。

举例来说，一般成人每天总能量摄入为1200-1500千卡，共需12-16份食物，其中谷薯类占5-7份、蔬菜类占1份、水果占1份、肉蛋类占3份、乳类占1.5份、豆制品占1份、油脂类占1.5份。

**1个食物交换份互换举例**

**谷薯类**

大米、小米、高粱米、燕麦、粉丝、玉米面、绿豆、豌豆可以随意替换，只要重量是**25克**，都为1个食物交换份。

**蔬菜类**

**300克**深色蔬菜如油菜、菠菜、芹菜，**330克**浅色蔬菜如大白菜、娃娃菜、菜花，**375克**茄果类如西红柿、南瓜、黄瓜，可以随意替换，都为1个食物交换份。

**水果类**

**200克**柑橘类水果如橙子、柚子、柠檬，**175克**瓜果类水果如苹果、梨、李子、桃、杏儿、西瓜，**150克**浆果类水果如葡萄、草莓、猕猴桃，可以随意替换，都为1个食物交换份。

**肉蛋类**

**50克**的猪肉、鸡肉、兔肉、鸭肉，也可以与**60克**的鸡蛋和**90****克**的鱼、虾、贝类随意替换，都为1个食物交换份。

（参考文献：中国营养学会《食物交换份T/CNSS 020-2023》）

掌握食物交换份算法，就可以根据个人喜好随意组合，让搭配更丰富。

**其次要迈开腿**

“吃动平衡”最重要的评价指标就是体重和腰围。我们建议糖尿病患者胖的减重；瘦的恢复体重，另外增肌、减脂，争取腰围达标。

✦ 糖尿病患者可在餐后运动，每周至少5天，每次30~45分钟，中等强度运动要占 50%以上，循序渐进，持之以恒。

✦ 中等强度运动包括快走、骑车、乒乓球、羽毛球、慢跑、游泳等。

✦ 如无禁忌，最好一周2次抗阻运动，如哑铃、俯卧撑、器械类运动等，提高肌肉力量和耐力。

**小TIPS：****“汤糖躺烫”**

1. 减少流质、半流质摄入，尽量摄入固体类食物，细嚼慢咽；

2. 减少单糖类食物比如糖、糕点、蜂蜜、饮料、果汁；

3. 避免饭后久坐不动；

4. 避免进食速度过快、过多。

**减少并发症的发生**

严格的血糖控制可以明显减少慢性并发症的风险。尽管目前我们还没有根治糖尿病的办法，但是有非常多有效控制高血糖的方法。

大部分患者长期严格地控制好血糖，完全可以保持跟正常人一样的生活质量。从这个意义上来说，延长并发症的发病时间，也是一种糖尿病治疗的“逆转”。
